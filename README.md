# 📰 Fake News Detection with Live News Classification

This project uses machine learning and natural language processing (NLP) to classify news articles as **FAKE** or **REAL**. It supports both static datasets and **live news scraping** from URLs.

---

## 🚀 Features

- ✅ Train a Naive Bayes classifier on real-world news datasets
- ✅ Preprocess news text using NLP techniques
- ✅ Use TF-IDF for feature extraction
- ✅ Detect fake news from any online article via URL using `newspaper3k`
- ✅ Easily extendable and Colab-compatible
